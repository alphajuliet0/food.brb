Design direction v1

Idea

One glance, one thumb. The ring owns the top; the floating dock owns the thumb zone; the centre plus is the one action he does all day. Everything else is quiet.

Type

34/700 hero number (tabular) · 28/700 screen titles · 17/600 card titles · 15/400-600 body and values · 13 meal names · 11/600 +8% caps labels. All numbers tabular.

Spacing

4pt grid. 20 screen gutter, 20 card padding, 28 hero radius, 20 panel, 14 tile/field, 28 section gaps. Panels separated by space, not borders; hairlines only where rows need scanning.

Colour

calories  protein  fibre  complete. Only these carry meaning; everything else is ink on paper. Light: #F2F2F7 / white. Dark: #000 / #1C1C1E.

Components

Floating panels on a flat canvas (no outlines). Icon-only circular buttons. Segmented control for meals. Stat tiles with big tabular numbers. Floating dock: Today, Week, raised centre +, You. Bones are layered surfaces, so the Liquid Glass pass later is a material swap, not a rebuild.
