# food.brb

A private, installable food, training and wellbeing tracker for Ajay, adapted from Sadhana with the source owner's explicit permission.

- Static vanilla HTML, CSS and JavaScript
- Data stays in browser localStorage unless exported
- Health CSV import supports date, weight_kg or weight_lb, waist_in, steps and sleep_h
- Barcode search uses Open Food Facts
- Gemini estimates require the user's own API key
